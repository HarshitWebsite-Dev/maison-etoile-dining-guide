# Maison Etoile Dining Guide

Build a stunning luxury restaurant website called “Maison Étoile”.

I want a premium editorial design inspired by high-end European restaurants.

Design:

Black, ivory and champagne gold palette.

Beautiful full-width food photography.

Elegant serif typography.

Minimalist and luxurious layout.

Sections:

Stunning hero section with restaurant name.

Our story.

Signature dishes with photographs.

Food menu.

Customer reviews.

Reservation section.

Contact and location.

Make it fully responsive for desktop and mobile. Add smooth animations, interactive buttons and beautiful transitions. Make it look like a high-end professionally designed website, not a generic template.
